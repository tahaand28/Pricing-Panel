# Pricing Panel

A modern pricing panel built with pure HTML and CSS, designed to present different pricing plans in a clean and structured interface.

The project focuses on creating a simple and visually appealing pricing component with a clear layout and organized presentation of plans and features.

## ✨ Features

* Clean and modern pricing panel
* Structured pricing plans
* Clear presentation of features
* Responsive-friendly layout
* Custom styling with CSS
* Built with pure HTML and CSS
* Separate pricing panel structure from the animated background

## 🛠️ Technologies

* HTML5
* CSS3
* Responsive Web Design

## 🎯 Project Goal

The main goal of this project was to practice building a modern pricing component from scratch using HTML and CSS, with a focus on layout structure, visual hierarchy, and clean UI implementation.

# پنل قیمت‌گذاری

این پروژه یک پنل قیمت‌گذاری مدرن است که با استفاده از HTML و CSS طراحی شده و برای نمایش مرتب و واضح پلن‌ها و امکانات مختلف مورد استفاده قرار می‌گیرد.

تمرکز اصلی پروژه روی ایجاد یک ساختار تمیز و منظم برای نمایش پلن‌های قیمت‌گذاری و طراحی یک رابط کاربری ساده و کاربردی بوده است.

## ✨ ویژگی‌ها

* طراحی مدرن و تمیز پنل قیمت‌گذاری
* نمایش منظم پلن‌های مختلف
* ارائه واضح امکانات هر پلن
* ساختار مناسب برای طراحی ریسپانسیو
* استایل‌دهی سفارشی با CSS
* توسعه با HTML و CSS خام
* جداسازی ساختار پنل قیمت‌گذاری از پس‌زمینه متحرک

## 🛠️ تکنولوژی‌های استفاده‌شده

* HTML5
* CSS3
* طراحی واکنش‌گرا (Responsive Web Design)

## 🎯 هدف پروژه

هدف اصلی این پروژه تمرین طراحی و پیاده‌سازی یک کامپوننت قیمت‌گذاری از صفر با HTML و CSS بوده است؛ با تمرکز بر ساختار صفحه، سلسله‌مراتب بصری، چیدمان مناسب و طراحی رابط کاربری تمیز.
